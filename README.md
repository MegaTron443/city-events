Вебзастосунок для перегляду та збереження міських культурних заходів із клієнтським роутингом, роботою з IndexedDB та власним REST API на базі Express.js.

### 1. Виявлені вразливості (XSS)
* **Проблема:** У методах рендерингу карток (`generateEventCardHTML`), деталей (`renderEventDetailsView`) та збережених подій (`renderSavedEventsView`) використовувався `innerHTML` із прямою інтерполяцією динамічних даних (`title`, `location`, `category`).
* **Підтвердження загрози:** Введення тестового рядка `<img src=x onerror="alert('XSS')">` у форму додавання події викликало спрацювання JavaScript-коду (DOM-based / Stored XSS).

### 2. Спосіб виправлення
* Реалізовано функцію екранування спеціальних символів `escapeHTML()`, яка конвертує символи `&`, `<`, `>`, `"`, `'` у безпечні HTML-сутності.
* Усі динамічні поля, що надходять з API, форми або IndexedDB, перед вставкою в HTML-шаблони проходять обов'язкову санітизацію.
* Після виправлення тестовий пейлоад відображається виключно як звичайний безпечний текст.

### 3. Аудит клієнтських сховищ (localStorage / IndexedDB)
* **Зміст даних:** Зберігаються публічні властивості обраних подій (`id`, `title`, `date`, `location`) та прапорець міграції.
* **Чутлива інформація:** Паролі, персональні дані користувачів або токени доступу відсутні.
* **Рівень ризику:** Низький.

### 4. Керування секретами та захист з'єднання
* **Секрети:** У вихідному коді відсутні захардкоджені API-ключі чи конфіденційні паролі.
* **HTTPS:** При публікації (Vercel / Netlify / Render) з'єднання захищається протоколом HTTPS з автоматичним SSL/TLS-сертифікатом та примусовим редиректом з HTTP для запобігання перехопленню трафіку (MitM).
